# CSV templates

These files contain fictional planning data, not passwords. Replace the reserved `example.invalid` domain with a verified lab domain in a private working copy.

- `users-template.csv`: initial test identities and departments.
- `membership-plan.csv`: initial and final direct memberships for Lab 01.

These schemas are not directly compatible with the Entra portal bulk-import template. For a future bulk-import lab, download the current template from the portal and map these fields to it.
